# Атлас правил НРИ «Кольцо Всевластья»

[Открыть интерактивный атлас](https://kargon55.github.io/the-one-ring-atlas/)

Это исходники самостоятельного Атласа и готовый автономный HTML. Ручная схема в Obsidian была черновиком; сборка её не читает и не меняет.

## Структура

- `atlas/content/sections/` — карточки по параграфам: текст, таблицы и страницы книги.
- `atlas/content/manifest.json` — порядок параграфов и карточек.
- `atlas/graph/edges.json` — связи и направления стрелок.
- `atlas/graph/layout.json` — расположение карточек и групп.
- `atlas/app/` — HTML-разметка, CSS, JavaScript и логотип.
- `atlas/build/build_atlas.py` — проверка данных и сборка.
- `index.html` — опубликованный автономный Атлас; сборщик создаёт также `outputs/Кольцо Всевластья — схема правил.html` для локального использования.

Для новых правок используйте `atlas/`. Исторические файлы ручной схемы в этот репозиторий не входят.

## Сборка и проверка

Из корня репозитория:

```powershell
python atlas/build/build_atlas.py
```

Сборщик создаёт один HTML со встроенными данными, стилями, кодом и логотипом. Он открывается локально через `file://`. Публикация сайта выполняется отдельно и только по явной команде владельца: готовый HTML копируется в `index.html` и отправляется в GitHub.
