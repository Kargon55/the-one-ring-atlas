# Данные Атласа

Карточка хранится в файле своего параграфа (`content/sections/`). `id` карточки постоянен и читаем: английский код параграфа и английское название правила через дефис, например `shadow-harden-will`. `parts` — её видимый текст, `table` — таблица, `pages` — страницы книги. Порядок карточек и параграфов задаёт `content/manifest.json`.

`graph/edges.json` хранит только действующие связи: `a` и `b` — ID карточек. `start` относится к концу у `a`, `end` — к концу у `b`; значение `arrow` означает наконечник стрелки, `null` — его отсутствие. ID связи составлен из ID обеих карточек. `labels` задаёт подписи переходов. Геометрию стрелки рассчитывает интерфейс; изменение расположения не меняет направление связи.

`graph/layout.json` хранит координаты карточек и рамки групп отдельно от их текста и связей. Каждая карточка должна принадлежать ровно одному параграфу, а каждая связь должна указывать на существующие карточки. Сборщик проверяет эти условия.

Для изменения правила редактируйте соответствующий файл параграфа, затем выполните `python atlas/build/build_atlas.py` и `python work/check_integrity.py`. Готовый файл в `outputs/` можно открыть локально. Публикация на сайт — отдельное действие.
